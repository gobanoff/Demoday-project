# Demoday-project
## Overview

The **Demoday Project** is a web-based application that allows users to submit and review data through interactive forms. The project demonstrates full-stack development using **pure PHP** for backend functionality and **Bootstrap** for the frontend design. The application is live and can be accessed [here](http://gobanoff.great-site.net/index.php).

## Features

- User-friendly form submissions
- Review and manage user-submitted data
- Responsive design using Bootstrap
- Backend developed using pure PHP
- SQL database for secure data storage

## Technologies Used

- **Frontend**: HTML, CSS, Bootstrap
- **Backend**: PHP (no frameworks)
- **Database**: MySQL (or another SQL database)
- **Version Control**: Git
- **Deployment**: Hosted live at [gobanoff.great-site.net](http://gobanoff.great-site.net/index.php)
